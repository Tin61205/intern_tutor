# intern_tutor
# 📚 Lộ trình thực hành

Toàn bộ project được chia thành 7 session.

| Session | Nội dung |
|----------|-----------|
| Session 1 | FastAPI Fundamentals & Project Structure |
| Session 2 | Database, SQLAlchemy, Alembic & CRUD |
| Session 3 | Authentication (JWT) |
| Session 4 | Authorization, Middleware & Exception Handling |
| Session 5 | Redis Cache & API Documentation |
| Session 6 | Configuration, Logging & Testing |
| Session 7 | Docker & Production Deployment |

Mỗi session đều được phát triển trên chính project này và có branch riêng để dễ dàng theo dõi quá trình phát triển của hệ thống.
